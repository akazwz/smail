## Email jetable pour codes de vérification

Utilisez un **email jetable pour la vérification** lorsqu'un site veut vous envoyer un code ou un lien de confirmation avant de vous laisser entrer, et que vous préférez ne pas lui confier votre adresse principale.

### Ce que vous pouvez recevoir

- Codes à usage unique (OTP) pour une inscription ou une connexion
- Liens « confirmez votre email »
- Emails d'activation et de bienvenue
- Liens de création de mot de passe pour un nouveau compte

### Recevoir un code, étape par étape

1. Générez une adresse sur la page d'accueil de smail.pw et copiez-la.
2. Saisissez-la sur le site qui demande la vérification et demandez le code.
3. Restez sur la page smail.pw. L'email apparaît automatiquement dans la boîte de réception : inutile d'actualiser sans arrêt.
4. Ouvrez l'email et relevez le code. S'il s'agit d'un lien, cliquez dessus : les liens s'ouvrent dans un nouvel onglet, si bien que la page de confirmation du site se charge normalement.

### En combien de temps il arrive

La remise à smail.pw elle-même prend quelques secondes. L'essentiel de l'attente vient de l'expéditeur : beaucoup de services placent leurs emails de vérification en file d'attente, et un délai d'une à trois minutes est courant aux heures de pointe. Les codes expirent souvent au bout de 5 à 15 minutes : ne demandez donc le code qu'une fois la page smail.pw déjà ouverte.

### Si le code n'arrive pas

Procédez dans l'ordre :

1. Vérifiez qu'il n'y a pas de faute de frappe dans l'adresse. Utilisez le bouton Copier plutôt que de la saisir à la main.
2. Attendez deux ou trois minutes, puis cliquez une fois sur **Actualiser**.
3. Utilisez l'option « renvoyer le code » du site, une seule fois. Demander plusieurs codes d'affilée invalide souvent les précédents.
4. Si rien n'arrive après un renvoi, le site bloque probablement les domaines d'email temporaire. Une nouvelle adresse smail.pw n'y changera rien, car toutes les adresses utilisent le même domaine. Pour ce site, utilisez une boîte mail permanente ou un alias email.

### À savoir

- Seul le corps du message est affiché. Les pièces jointes ne sont pas affichées.
- La boîte fonctionne en réception seule : vous ne pouvez pas répondre à un email de vérification.
- Gardez la même adresse jusqu'à ce que vous ayez terminé. La remplacer ou la supprimer est irréversible, et un code envoyé à l'ancienne adresse ne peut plus être lu.
- L'adresse reste dans le navigateur où vous l'avez générée : une adresse créée sur votre téléphone ne peut pas être ouverte sur votre ordinateur portable.

### Quand ne pas l'utiliser

N'utilisez pas de boîte jetable pour les codes de double authentification des comptes qui comptent : banque, paiements, travail, administration ou vos principaux comptes de réseaux sociaux. Si vous perdez un jour l'adresse, vous perdez la possibilité de vous connecter.
