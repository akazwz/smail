## 인증 코드용 일회용 이메일

사이트가 이용을 허락하기 전에 코드나 인증 링크를 보내려 하는데 평소 쓰는 주소는 알려 주고 싶지 않다면 **인증용 일회용 이메일**을 사용하세요.

### 받을 수 있는 것

- 회원가입이나 로그인에 쓰는 일회용 코드(OTP)
- '이메일 인증' 링크
- 계정 활성화 메일과 환영 메일
- 새 계정의 비밀번호 설정 링크

### 단계별 코드 받는 방법

1. smail.pw 홈페이지에서 주소를 생성하고 복사합니다.
2. 인증을 요구하는 사이트에 주소를 입력하고 코드를 요청합니다.
3. smail.pw 페이지에 그대로 머무릅니다. 메일이 받은편지함에 자동으로 나타나므로 계속 새로고침할 필요가 없습니다.
4. 메일을 열어 코드를 확인합니다. 링크라면 클릭하세요. 링크는 새 탭에서 열리므로 사이트의 인증 페이지가 정상적으로 표시됩니다.

### 도착하는 데 걸리는 시간

smail.pw까지 전달되는 데는 몇 초면 충분합니다. 기다리는 시간의 대부분은 발신 측에서 생깁니다. 인증 메일을 대기열에 넣어 차례로 보내는 서비스가 많아서, 사용자가 몰리는 시간대에는 1~3분 걸리는 일이 흔합니다. 코드는 5~15분 안에 만료되는 경우가 많으니, smail.pw 페이지를 먼저 열어 둔 다음에 코드를 요청하세요.

### 코드가 도착하지 않을 때

다음을 순서대로 확인하세요.

1. 주소에 오타가 없는지 확인합니다. 직접 입력하지 말고 '복사' 버튼을 사용하세요.
2. 2~3분 기다린 뒤 **새로고침**을 한 번 누릅니다.
3. 사이트의 '코드 재전송' 기능을 한 번만 사용합니다. 코드를 연달아 여러 번 요청하면 앞서 받은 코드가 무효가 되는 경우가 많습니다.
4. 재전송한 뒤에도 아무것도 오지 않는다면 그 사이트가 임시 이메일 도메인을 차단하고 있을 가능성이 큽니다. 모든 smail.pw 주소는 같은 도메인을 쓰기 때문에 새 주소를 만들어도 소용이 없습니다. 그 사이트에는 장기적으로 사용하는 이메일이나 이메일 별칭을 쓰세요.

### 알아 둘 점

- 메일 본문만 표시됩니다. 첨부 파일은 표시되지 않습니다.
- 받은편지함은 수신 전용이어서 인증 메일에 답장할 수 없습니다.
- 일이 끝날 때까지 같은 주소를 유지하세요. 주소를 교체하거나 삭제하면 되돌릴 수 없으며, 이전 주소로 보낸 코드는 더 이상 읽을 수 없습니다.
- 주소는 주소를 생성한 브라우저에만 남아 있습니다. 휴대폰에서 만든 주소를 노트북에서 열 수는 없습니다.

### 사용하면 안 되는 곳

은행, 결제, 업무, 정부 서비스, 주로 쓰는 소셜 계정처럼 중요한 계정의 2단계 인증 코드에는 일회용 받은편지함을 사용하지 마세요. 혹시라도 주소를 잃으면 로그인할 수 없게 됩니다.
