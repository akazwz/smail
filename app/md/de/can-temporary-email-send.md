## Kann eine temporäre E-Mail Nachrichten senden?

Kurz gesagt: **Auf smail.pw nicht.** Eine smail.pw-Adresse kann E-Mails empfangen, aber weder senden noch antworten. Das gilt für die meisten Dienste für temporäre E-Mails, und es ist Absicht.

### Was eine smail.pw-Adresse kann und was nicht

Sie kann:

- E-Mails von jedem Absender empfangen
- Den Nachrichtentext anzeigen, als HTML oder als reinen Text
- Links aus der E-Mail in einem neuen Tab öffnen

Sie kann nicht:

- Eine neue E-Mail senden
- Auf eine empfangene E-Mail antworten oder sie weiterleiten
- Anhänge anzeigen oder herunterladen

### Warum es keinen Versand gibt

- **Missbrauch.** Eine Adresse, die jeder mit einem Klick erstellen kann und hinter der keine Identität steht, ist genau das, was sich Spammer und Betrüger als Absender wünschen. Weil smail.pw nur empfängt, fällt diese Nutzung komplett weg.
- **Zustellbarkeit.** Eine Domain, die anonyme E-Mails verschickt, wird von anderen Anbietern schnell blockiert. Ist es so weit, leiden auch seriöse E-Mails, die mit dieser Domain zu tun haben.
- **Einfachheit und Kosten.** Für den Empfang braucht es keine Absenderreputation, keine Warteschlangen für ausgehende E-Mails und keine Bearbeitung von Beschwerden. Auch deshalb kann der Dienst kostenlos bleiben.

### Wenn eine Website zur Bestätigung eine Antwort verlangt

Einige wenige Dienste verifizieren dich, indem du auf ihre E-Mail antworten oder eine Nachricht an eine spezielle Adresse schicken sollst. Das kann ein temporäres Postfach nicht. Such auf derselben Seite nach einer Alternative, denn die meisten Dienste bieten auch einen Link oder einen Code an, oder nutze für diesen Dienst ein dauerhaftes Postfach.

### Wenn du eine Wegwerfadresse brauchst, die senden kann

Nutze stattdessen einen E-Mail-Alias bei einem normalen Anbieter. Ein Alias leitet an dein echtes Postfach weiter und lässt dich von der Alias-Adresse aus antworten. So sieht die Gegenseite deine Hauptadresse nie, und du kannst den Alias später abschalten. Unser Artikel [Temporäre E-Mail vs. E-Mail-Alias](/blog/temporary-email-vs-email-alias) vergleicht die beiden.

### Was der Empfang umfasst

- Neue E-Mails erscheinen innerhalb von Sekunden auf der geöffneten Seite.
- E-Mails, die größer als 5 MB sind, werden ohne ihre Anhänge gespeichert; der Text der Nachricht bleibt erhalten.
- Adressen und E-Mails bleiben standardmäßig langfristig erhalten, aber ohne Garantie.
